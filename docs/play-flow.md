# เส้นทางเล่นที่อ่านน้อย

ใช้กับหน้าแรก หน้ารายชื่อห้อง การสร้างห้อง ล็อบบี้ และกระดานทุกเกม

- หน้าแรกคงแบบเดิม: โปรไฟล์และปุ่มเริ่มเกม/เล่นคนเดียว/ตั้งค่า พร้อม leaderboard ข้างกันบนคอมและเรียงลงบนมือถือ ไม่แสดงรายการหรือภาพเกม เลือกเกมหลังเข้าเริ่มเกม
- ใช้ค่าเริ่มต้นที่เล่นได้ทันที พับการตั้งค่าที่ไม่บังคับไว้ ส่วนการเลือกทีมที่จำเป็นต้องเห็นก่อนเริ่ม
- หน้าห้องรอต้องเห็นจำนวนคนที่ยังขาด ปุ่มชวนเพื่อน และเริ่มเกม โดยไม่ต้องเลื่อนผ่านแชท
- คู่มือ ข่าวอัปเดต และทัวร์เปิดเมื่อผู้เล่นเลือกเอง ไม่เด้งทับตาเล่น
- แสดงค่าใช้จ่าย ความเสี่ยง ผลสกิล และผลแพ้ชนะตรงจุดใช้งาน ไม่ซ่อนข้อมูลที่ใช้ตัดสินใจ
- ใช้สถานะเลือกแล้ว ล็อกแล้ว และปุ่มที่ระบุสิ่งที่จะเกิดขึ้น แทนคำสอนซ้ำ

## ตรวจสอบ

`npm run smoke:play:flow` ใช้ข้อมูลชั่วคราว ปิด MongoDB และเปิด browser ตรวจครบ 17 เกม ตั้งแต่สร้างห้องด้วยค่าเริ่มต้น คัดลอกลิงก์ชวน รอผู้เล่น จนเริ่มเกม พร้อมตรวจจอมือถือและคอม ไม่มีคู่มืออัตโนมัติและ JavaScript error

`PLAY_FLOW_MODES=blackmarket,slave npm run smoke:play:flow` เลือกตรวจบางเกมได้ ภาพหน้าจอถูกบันทึกในโฟลเดอร์ชั่วคราวที่คำสั่งรายงาน

`npm run smoke:blackmarket:strategy` ตรวจการตัดสินใจของบอทและเล่นจำลอง 600 เกม รวมทดสอบว่าการเปลี่ยนข้อมูลลับของคู่แข่งไม่เปลี่ยนการตัดสินใจ

## สลาฟ

หนึ่งเกมมี 2 รอบ รอบแรกจบแล้วพัก 6.5 วินาทีก่อนแจก/แลกไพ่รอบสอง คะแนนต่อรอบเป็น 4/3/2/1 ตามอันดับ รวมสองรอบสูงสุดชนะ คะแนนสูงสุดเท่ากันชนะร่วม หน้าผลแสดง 10 วินาทีก่อนเซิร์ฟเวอร์พาทั้งห้องกลับล็อบบี้ โดยคงสมาชิกไว้

บันทึกประวัติและอันดับเมื่อจบเกมเท่านั้น โต๊ะบอทเก็บประวัติของคนแต่ไม่นับอันดับ เกมทดสอบหรือออกกลางเกมไม่นับผล แมตช์รูปแบบเก่าที่ค้างอยู่จบรอบปัจจุบันแล้วกลับล็อบบี้ โดยไม่แก้ผลที่เคยบันทึก

ปุ่มเสียง เพลง แชท ออก และวิธีเล่นใช้ไอคอนร่วมกันจาก `public/assets/ui` มีชื่อสำหรับเครื่องมือช่วยอ่านและสถานะปิดเสียง ไพ่มือสลาฟแสดงแถวเดียวทุกขนาดจอและไม่ขยับหลบจุดแตะขณะกด
